# Design Ticket Selection Interface

A ticket-booking interface prototype built from a Figma design. It guides a user through zone selection, ticket type, checkout, payment, and success or error screens.

## Project process

The project notes record a completed layout pass to keep screens at a consistent 4:3 ratio during navigation. The documented fix standardized content wrappers and action placement across ticket, checkout, payment, success, and error screens.

## Design reference

[Figma design: Ticket Selection Interface](https://www.figma.com/design/XgpFAaT42aiy1gVlwKp0CG/Design-Ticket-Selection-Interface)

## Tech stack

- React, TypeScript, Vite
- Tailwind CSS and Radix UI components

## Run locally

Prerequisites: Node.js and npm.

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
``
